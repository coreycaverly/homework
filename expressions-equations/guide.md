**Unit 4.** Exponents, writing expressions with letters, and solving one-step equations.
Big idea for equations: **do the same thing to both sides** to get the letter alone.

## Exponents

An exponent is **repeated multiplication**. In 5³, 5 is the **base** and 3 is the
**exponent**: 5³ = 5 × 5 × 5 = **125**. (It is *not* 5 × 3.)

## Expression words

| Word | Means |
| --- | --- |
| **Variable** | a letter that stands for a number (x, n) |
| **Coefficient** | the number multiplied by the variable (in 4x, it's 4) |
| **Term** | a number or variable chunk (4x, 7, 2n are terms) |
| **Expression** | numbers/variables with operations, **no equals sign** (3x + 2) |
| **Equation** | two expressions set **equal** (3x + 2 = 11) |

**Evaluate** an expression by **substituting** the value in: if x = 5, then 3x + 2 =
3·5 + 2 = **17**. (Use order of operations: multiply before add.)

**Write it from words:** "7 more than a number" → n + 7 · "triple a number" → 3n ·
"a number split into 4 equal parts" → n ÷ 4.

## Equivalent expressions

- **Combine like terms:** 3x + 5x = **8x** (same letter). But 3x + 5 **can't** combine.
- **Distribute:** 4(x + 2) = 4x + 8 (multiply the 4 by **each** term inside).

## Solving one-step equations

Undo the operation with its **inverse**, and do it to **both sides**.

| Equation | Inverse | Solution |
| --- | --- | --- |
| x + 6 = 10 | subtract 6 | x = **4** |
| x − 3 = 5 | add 3 | x = **8** |
| 4x = 20 | divide by 4 | x = **5** |
| x ÷ 2 = 6 | multiply by 2 | x = **12** |

> **Check it:** put your answer back in. 4x = 20 → 4·5 = 20 ✓

## Cheat card

|  | Do this |
| --- | --- |
| **Exponent** | base × base × … (5³ = 5·5·5, not 5·3) |
| **Evaluate** | substitute, then order of operations |
| **Like terms** | add only matching letters (3x + 5x = 8x) |
| **Distribute** | 4(x+2) = 4x + 8 |
| **Solve** | inverse operation, both sides, then check |
