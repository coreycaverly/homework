**Unit 7.** Negative numbers, the number line, absolute value, and the coordinate plane.
Big idea: **the number line keeps going left past zero** — into the negatives.

## Negatives and the number line

Numbers get **smaller to the left**, bigger to the right. This is true for negatives too:
**−5 is less than −2** (it's farther left). Negatives show things like below zero,
owing money, or below sea level.

| Words | Symbol |
| --- | --- |
| **Opposite** of a number | same distance from 0, other side (opposite of 6 is −6) |
| **Absolute value** |x| | the **distance from 0** — always **0 or positive** |

> |−7| = 7 and |7| = 7. Both are 7 units from zero.

### Trap: more negative = smaller

−10 < −3, even though 10 > 3. Picture the number line: −10 is farther **left**, so it's less.

## Comparing and ordering

Put them on a number line and read **left (least) to right (greatest)**.
> Order −3, 1, −5, 2 → **−5, −3, 1, 2**.

## The coordinate plane

Two number lines cross at the **origin (0, 0)**: the **x-axis** (across) and **y-axis** (up/down).
A point is an **ordered pair (x, y)** — **x first (across), then y (up/down).**

| Quadrant | x | y |
| --- | --- | --- |
| **I** (top right) | + | + |
| **II** (top left) | − | + |
| **III** (bottom left) | − | − |
| **IV** (bottom right) | + | − |

> (−3, 2) → left 3, up 2 → Quadrant II.

## Cheat card

|  | Remember |
| --- | --- |
| **Smaller number** | farther **left** on the line (−8 < −1) |
| **Opposite** | flip the sign (−x) |
| **Absolute value** | distance from 0, never negative |
| **Ordered pair** | (x, y) = across, then up/down |
| **Quadrants** | I, II, III, IV counter-clockwise from top-right |
