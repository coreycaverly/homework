## Start here: the pass method

Do one section a day, about 5 minutes each. Set a timer, then stop when it rings.

**Your goal:** find every mistake the worksheet is hiding. You're not done until
every one is crossed off.

1. **Count first.** Note how many of each type you're looking for.
2. **One pass per type.** Read through once looking only for TYPE_1, again for
   TYPE_2, and so on. Cross one off for each fix.
3. **Read it out loud.** If a sentence sounds wrong or doesn't make sense, a mistake
   is still hiding there.

**Brain tip:** finger under each word, a 30-second stretch between passes, and the
second paragraph counts just as much as the first.
