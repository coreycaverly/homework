**Unit 1.** Area is the number of unit squares that cover a flat shape. The whole trick:
**cut a hard shape into easy ones** (rectangles and triangles), find each area, then add.

## Key words

| Word | Means |
| --- | --- |
| **Area** | how many unit squares cover a shape (units²) |
| **Base** | one side you measure from |
| **Height** | the distance **straight across (perpendicular)** from the base to the top — **not** the slanted side |
| **Polygon** | a closed shape with straight sides |
| **Net** | a flat pattern that folds up into a 3-D shape |
| **Face** | one flat side of a 3-D shape |

## Area formulas

| Shape | Formula | Example |
| --- | --- | --- |
| **Rectangle** | base × height | 6 × 4 = **24** |
| **Parallelogram** | base × height | 6 × 4 = **24** (height is perpendicular!) |
| **Triangle** | **½ × base × height** | ½ × 8 × 3 = **12** |

> **Why ½ for a triangle?** Two copies of a triangle make a parallelogram, so one triangle
> is **half** of base × height.

### Trap: use the PERPENDICULAR height

The height makes a right angle with the base. On a tilted triangle or parallelogram, the
height is **not** the slanted edge — it's the straight-across distance.

## Weird shapes: decompose

Cut the shape into rectangles and triangles, find each area, then **add them up**. (Or
find a big rectangle and **subtract** the missing corner.)

## Surface area

**Surface area = the area of every face, added together.** Unfold the 3-D shape into its
**net** so you can see all the faces.

> A box (rectangular prism) has 3 pairs of matching faces. Find the area of the 3 different
> faces, double each, and add: SA = 2(lw) + 2(lh) + 2(wh).

## Cheat card

|  | Do this |
| --- | --- |
| **Parallelogram** | base × perpendicular height |
| **Triangle** | ½ × base × perpendicular height |
| **Messy polygon** | cut into rectangles + triangles, add |
| **Surface area** | draw the net, add every face's area |
| **Units** | area is always in **square** units (cm², in²) |

## Practice

1. Parallelogram, base 10, height 3. Area? 
2. Triangle, base 12, height 5. Area?
3. A box 4 × 3 × 2. Surface area?

## STOP & CHECK

- ☐ I used the **perpendicular** height, not the slanted side.
- ☐ Triangle areas have the **½**.
- ☐ My answer is in **square units**.
